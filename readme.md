# 🕸️ NeuroWeb // Synaptic Action Potential & Neural Dynamics Lab

An interactive computational neuroscience sandbox simulating membrane potentials, axonal action potential propagation, Hebbian plasticity, and collective EEG rhythms using Vanilla JavaScript and HTML5 Canvas.

## 🌐 Live Demo
Interact with the neural mesh: [https://rohitmaity10.github.io/neuroweb-sim/](https://rohitmaity10.github.io/neuroweb-sim/)

## Technical Highlights
- **Hodgkin-Huxley Membrane Dynamics:** Models resting membrane potential (-70 mV), threshold depolarization (-55 mV), refractory periods, and all-or-nothing action potentials (+35 mV).
- **Axonal Waveguide Propagation:** Action potentials travel physically along connecting synaptic branches with real-time bioluminescent pulse rendering.
- **Hebbian Learning (STDP):** Active synaptic pathways dynamically thicken and strengthen their conduction efficacy with each transmission.
- **Neuromodulatory Baths & EEG Monitor:** Toggle between Dopamine, GABA, and Glutamate baths to watch the collective rhythm shift between synchronized Alpha, Beta, and Gamma oscillations on a live oscilloscope.
- **Interactive Micro-Tools:** Depolarize somas with the electrode, graft new neurons, or perform axotomies by slicing connection tracts with a scalpel cursor.
